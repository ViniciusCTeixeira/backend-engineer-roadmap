## Activities

### GitHub CLI reading — 20 min — `SOLO`

Review `gh` repository/PR/status commands. Do not configure hosted Actions.

Use a disposable/local branch workflow and safe `gh` inspection where authenticated.

### Commit/PR narrative — 20 min — `SOLO`

Prepare a reviewable commit sequence and PR-style description with scope/evidence/validation.

### English review note — 10 min — `SOLO`

Write one English review comment that cites evidence rather than preference.

### Daily micro-assessment — 20 min — `SOLO`

Complete the Git/GitHub CLI assessment.

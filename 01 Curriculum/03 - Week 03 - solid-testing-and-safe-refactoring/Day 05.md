# Day 05 — Git Branches and Agent-Assisted Test Review

## Outcome

Advance Week 3's primary outcome with observable evidence, not reading-only completion.

> Use SOLID and tests as feedback mechanisms to refactor behavior safely rather than applying patterns mechanically.

## Activities

### Git branch lab — 25 min — `SOLO`

Create a short-lived branch and inspect branch/commit relationships before merging.

### SOLO test review — 20 min — `SOLO`

Review your own tests first: missing behavior, coupling, weak assertions.

### Agent review — 25 min — `AI-ASSISTED`

Ask for test/code review only after your review; require each suggestion to name protected behavior/risk.

### Daily micro-assessment — 20 min — `SOLO`

Complete the Git/testing assessment without agent help.

### Decision note — 15 min — `HYBRID`

Accept/reject suggestions and justify each decision.

## Usage

1. Open the recipe.
2. Verify its preconditions.
3. Copy the `Ready-to-copy prompt`.
4. Run it from the repository root unless noted otherwise.
5. Review the resulting diff/state before committing.

Recipes are tool-agnostic where possible. Codex and Claude-specific bootstrap behavior is documented in `docs/agents.md`.

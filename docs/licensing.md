# Licensing Rationale

V1 uses a single **MIT License** for the repository.

## Why one license

The repository mixes:

- Markdown curriculum;
- templates;
- documentation;
- validation scripts;
- test fixtures;
- agent prompts/rules.

A single license keeps forks, educational reuse, adaptation, and contribution handling understandable.

## Why MIT

MIT is deliberately permissive.

It allows reuse, modification, redistribution, and commercial use while requiring preservation of the copyright/license notice and providing the repository without warranty.

For this project, that matches the goal of making the roadmap easy to:

- fork;
- adapt to another learner profile;
- translate;
- reuse inside a team;
- extend with new curriculum/resources;
- reuse validation/tooling code.

## What the license does not do

It does not grant rights to third-party material merely because a link to that material exists in the repository.

Linked documentation, specifications, trademarks, product names, logos, and other third-party content remain subject to their own terms.

Contributors should not copy substantial third-party course/documentation content into this repository without permission.

The roadmap generally links to primary sources and asks learners to use them directly.

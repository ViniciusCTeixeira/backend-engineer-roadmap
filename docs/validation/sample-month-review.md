## Coverage

- Week 1: PHP types, strict_types, Git state model, safe agent review, Project A baseline.
- Week 2: OOP, composition/inheritance, Composer, PSR-4, task decomposition, Project A boundaries.
- Week 3: SOLID, dependency inversion, PHPUnit, characterization tests, Git branches, Project A safe refactor.
- Week 4: errors/exceptions, systematic debugging, merge/rebase, revert/reset/reflog, Xdebug, Project A root-cause report.

Every week contains English, AI/agent practice, project work, review/assessment, and career observation. Supporting / Industry Platforms appears in Week 4 through Xdebug at supporting depth.

## Assessment integrity

- 28 public daily micro-assessments contain prompts only.
- 4 public weekly simulations contain prompts only.
- learner raw attempts belong in private `.study/`.
- SOLO assessments prohibit agent assistance before submission/abandonment.
- HYBRID simulations preserve the first SOLO phase.

## Resource coverage fix discovered by pilot

The pilot required four primary sources for already-approved topics that were missing from the C4 catalog: `php-oop-manual`, `php-errors-exceptions`, `phpunit-writing-tests`, and `xdebug-step-debugging`. Adding these is resource coverage maintenance, not a curriculum/depth change.

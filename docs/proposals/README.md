# Curriculum Improvement Proposals

This directory contains generalized, reviewable proposals for changes that require human approval before implementation.

Use `90 Templates/curriculum-proposal.md`.

A proposal may be created here only when evidence supports a generic curriculum issue rather than a single learner-specific gap.

Do not copy learner-identifying, employer-identifying, interview-confidential, or NDA-restricted evidence into public proposals.

Expected naming:

```text
YYYY-MM-DD-<short-slug>.md
```

Proposal creation does not authorize implementation. The affected curriculum, scoring, workload, technology depth, phase ordering, target role, certification strategy, or platform track must remain unchanged until a human explicitly approves the proposal.

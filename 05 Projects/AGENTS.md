# Project Agent Rules

Scope: everything under `05 Projects/`.

Follow root `AGENTS.md`.

## Learning-first implementation

Projects exist to produce engineering evidence, not to maximize agent-written code.

Respect each milestone's declared mode:
- SOLO: do not implement for the learner;
- HYBRID: learner goes first, then compare;
- AI-ASSISTED: implementation assistance is allowed, but require review, validation, and explanation.

Do not introduce a technology before the curriculum teaches its prerequisite concepts.

## Deliverables

Prefer evidence such as:
- tests;
- benchmarks;
- query plans;
- architecture diagrams;
- ADRs;
- runbooks;
- incident/debug notes;
- API documentation;
- deployment/observability evidence.

Do not use confidential employer/customer code or data.

# Projects

The V1 portfolio uses cumulative projects rather than disconnected tutorial apps.

## Project A — CakePHP Modernization Lab

Path: `01-cakephp-modernization/`

Purpose:
- stabilize and understand legacy code;
- protect behavior with tests;
- deepen CakePHP/runtime knowledge;
- improve SQL/caching;
- containerize and document operations;
- produce a modernization case study.

Primary period: Weeks 1–24.

## Project B — Production Backend Platform

Path: `02-production-backend-platform/`

Purpose:
- build a modern Laravel API;
- exercise MySQL/Redis/security/queues;
- deploy to AWS;
- add CI/CD, observability, Terraform and edge infrastructure;
- practice scale/reliability;
- integrate bounded AI features, RAG/evals and MCP.

Primary period: Weeks 17–52, with data/API pre-work starting earlier.

## Rules

- Respect the current curriculum prerequisites.
- Respect the milestone's `SOLO`, `HYBRID`, or `AI-ASSISTED` mode.
- Prefer engineering evidence over feature count.
- Never use confidential employer/customer code or data.
- Keep learner-specific implementation notes under `.study/` when they contain private information.

See `docs/design/project-progression.md`.

# Question Bank

This directory contains **public prompts**, not public answer keys.

## Diagnostic bank

Week 0 prompts live under:

`04 Question Bank/diagnostic/`

Each prompt has a stable ID such as:

```text
diag-mysql-explain-001
```

Day plans reference IDs instead of duplicating the prompt.

## Integrity rules

- Do not add model solutions next to scored prompts.
- Do not add exact expected outputs that effectively disclose a solution.
- Clarifications may be added only when they do not solve the task.
- Learner answers/results remain private under `.study/`.
- Review variants should use new stable IDs rather than rewriting a previously attempted prompt.
- Historical assessment instructions are not silently edited after a learner has attempted them.

## Future variants

D+1 / D+7 / D+30 variants may be added later with new IDs, for example:

```text
diag-mysql-explain-001-r1
diag-mysql-explain-001-transfer
```

The original attempted prompt remains unchanged.

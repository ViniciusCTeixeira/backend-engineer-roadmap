# Laravel Familiarity — Week 0 Diagnostic

These prompts diagnose entry depth. They are not public teaching examples and contain no answer keys.

| Field | Value |
|---|---|

| Mode | `SOLO` |
| Assessment type | `conceptual` |
| Difficulty | `diagnostic` |
| Estimated minutes | 20 |

### Prompt

Without pretending familiarity you do not have, map these backend concepts to Laravel if you know them:

- request lifecycle/middleware;
- dependency injection/service container;
- ORM/models/query building;
- validation;
- jobs/queues;
- events/listeners;
- testing.

For each item use one label: `can explain`, `recognize but shallow`, or `not used`. Then explain two concepts that transfer from CakePHP/general backend engineering even if Laravel-specific APIs are unfamiliar.

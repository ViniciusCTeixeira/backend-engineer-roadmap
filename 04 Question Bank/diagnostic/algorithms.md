### Prompt

Implement a function that receives an array of integer IDs and an integer `k`, and returns the `k` most frequent IDs.

Requirements:
- explain your chosen data structures;
- state time and space complexity;
- handle ties with a deterministic rule you define;
- include tests for at least three edge cases;
- do not use an LLM or search for a known solution during the attempt.

Use PHP unless another language is explicitly configured in private profile.

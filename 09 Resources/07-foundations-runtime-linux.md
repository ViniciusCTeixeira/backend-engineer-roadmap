## Selection notes

- PHP-FPM and CakePHP sources are core for Weeks 5–6.
- `curl`, `jq`, `ss`, `lsof`, `dig`, and GitHub CLI are supporting evidence tools.
- OpenSSH and Linux procfs support operational fundamentals.
- Hosted GitHub Actions is intentionally not enabled for this roadmap repository. GitHub Actions remains a later learning topic.
- Re-read current tool manuals when doing labs instead of memorizing flags.

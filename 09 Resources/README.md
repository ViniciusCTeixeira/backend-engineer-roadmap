## Resource use rule

A resource is not a task.

Generated daily study plans must specify:

- what to read/watch/use;
- what to practice;
- what evidence to produce;
- how mastery will be checked.

## Fast-moving content

AI/cloud/platform references are re-verified at task-generation/use time. `last_verified` is evidence of the last audit, not a guarantee that vendor behavior never changes.

# Career Track

The career track turns roadmap evidence into a progressive job-search campaign without letting one vacancy or interview rewrite the public curriculum.

## Year 1 target

Primary target roles:

- Senior Backend Engineer
- Senior Software Engineer — Backend
- Senior PHP Backend Engineer where the role demonstrates strong engineering depth

Core positioning:

> PHP/Laravel | MySQL | Redis | AWS | Distributed Systems | AI-Assisted Development

CakePHP is treated as valuable commercial and legacy-modernization experience, not as the learner's only professional identity.

## Campaign progression

| Period | Default career action |
|---|---|
| Months 1–2 | Observe target roles; no application quota |
| Month 3 | Start structured vacancy analysis |
| Month 4 | Prepare CV, LinkedIn, GitHub, and portfolio positioning |
| Month 5 | Begin selective applications |
| Month 6 | Use experimental interviews to collect real feedback |
| Months 7–9 | Run a regular application/interview campaign |
| Months 10–12 | Run an intensive campaign with evidence-driven remediation |

This is a default sequence, not a rule that forbids an earlier strong opportunity.

## Canonical private data

Learner-specific career data belongs only under `.study/career/`:

```text
.study/career/
├── jobs/
├── applications/
├── interviews/
└── market-signals/
```

Do not commit real employer names, application outcomes, interview notes, compensation data, relocation discussions, or other learner-specific career records to the public repository.

## Evidence rule

A single vacancy may update private preparation, expose a company-specific gap, or influence an application decision.

A single vacancy may not add a technology to the public curriculum, promote a supporting technology to core, or reorder the public roadmap.

A possible public curriculum change requires a recurring market signal across a meaningful recorded sample and still goes through the proposal process.

## Career success criteria

The track optimizes for stronger engineering work, not application volume or salary alone.

Useful outcomes include:

- increased backend depth and ownership;
- better technical interview performance;
- stronger technical English;
- demonstrable production/cloud experience;
- mature engineering practices;
- international collaboration exposure;
- credible future transfer/sponsorship options.

See `12 Year 2/` for the post-hire consolidation model.
